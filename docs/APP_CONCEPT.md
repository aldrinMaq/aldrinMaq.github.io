# APP_CONCEPT

Personal portfolio for Aldrin Maquiling. Resume PDF is the content source of truth for experience, skills, education, and featured work blurbs.

---

## Name

Aldrin Maquiling — Portfolio (`aldrinMaq.github.io`)

## One-liner

Static dark-theme portfolio showcasing fullstack work, commercial experience at mykuan.app, freelance projects, and personal/academic apps.

## Vision / problem

A single place for recruiters and clients to see experience, projects, skills, and contact — aligned with the downloadable resume.

## Who it's for

Hiring managers, clients, and collaborators evaluating Aldrin for fullstack / web development roles.

## Main flows

1. Land on hero → skim positioning
2. Read experience (mykuan + freelance)
3. Browse projects → open live demos
4. Check skills / education → contact or download resume

## Screens

Single page sections: Hero, Experience, Projects, Skills, Education & Honors, Contact.

## Features

- Resume-aligned copy for KUAN / mykuan.app
- Featured projects with live links where available
- Technical expertise tags matching the resume
- Resume PDF download
- Contact via email + GitHub

## Out of scope

- Blog, CMS, auth, backend
- Vue/Vite migration (unless requested)

## Constraints

- Keep existing visual language unless a redesign is requested
- Content must stay consistent with `Maquiling-Aldrin-Resume.pdf`

## Visual

- **Font:** Plus Jakarta Sans + JetBrains Mono
- **Accent:** emerald / teal on near-black zinc surfaces
- **Corner radius:** rounded-xl / rounded-2xl
- **Icon set:** Font Awesome 6

## Notes

- Commercial product: KUAN Store / mykuan.app
- Recent freelance: Courageous Public Health (WordPress/Elementor)
